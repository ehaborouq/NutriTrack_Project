NutriTrack: Smart Nutrition Dashboard
NutriTrack is a dynamic web application designed to help users monitor their daily calorie intake and receive intelligent nutritional feedback based on their eating habits.

What does it do?
The app allows users to log meals with specific categories, calculates the remaining daily calorie budget in real-time, and provides smart insights to help maintain a healthy lifestyle.

What is the "new feature" which you have implemented that we haven't seen before?
A smart behavioral insight system that analyzes dietary patterns and provides automated advice, integrated with a dynamic UI that visualizes progress using logic-driven color thresholds.

Prerequisites
